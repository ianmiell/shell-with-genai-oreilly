# AGENTS.md

`basic-script.sh` is a demo script for the course introduction. It is tracked
in git and is not an exercise: do not overwrite or rename it.

There are no task files here. If you are asked to write a solution to a task
from `part_i/`, `part_ii/` or `part_iii/`, put it in that task's folder as
`<task filename>.sh` (see the root `AGENTS.md`).
